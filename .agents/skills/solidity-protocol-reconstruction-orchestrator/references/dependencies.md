# Specialist skill dependencies

The orchestrator requires a framework-independent base and a detected framework specialist.

## Base mandatory

- `spec-to-code-compliance`
- `reverse-engineer`
- `audit-context-building`
- `entry-point-analyzer`
- `bdd-practices`
- `working-with-legacy-code`
- `property-based-testing`
- `secure-workflow-guide`

## Framework-routed mandatory

- Hardhat 2: `web3-testing`
- Hardhat 3: official `hardhat` from `NomicFoundation/hardhat-skills`
- Foundry: `foundry-solidity`
- Hybrid: both applicable specialists

## Hardhat 3 conditional companions

Load only when the corresponding package is declared/installed:

- `hardhat-toolbox-viem`
- `hardhat-toolbox-mocha-ethers`

## Optional

- `arc42-c4` with `--with-arc42`
- ADR capability with `--with-adrs`; preferred `documentation-and-adrs`, accepted aliases are listed in `skill-dependencies.yaml`

## Missing skill behavior

Do not approximate a missing specialist. Stop the affected phase and show the command generated by `scripts/install-dependencies.sh`.
